# New Anisha Jewellers — asset notes

## Photo handling
- `images/shop-exterior.jpg` / `.webp`: enhanced version of the newly supplied shop-front photo; used as the homepage hero.
- `images/owner-1.jpg` and `images/owner-2.jpg`: direct copies of the two supplied owner photos. **Do not retouch, enhance, AI-edit, or alter these images.** They are only resized by CSS for layout.
- `images/catalogue/real-*.jpg`: cleaned/cropped showroom/product references from the supplied Instagram screenshots. Instagram UI has been cropped out as far as practical; these are marked **REAL PHOTO** in the catalogue.
- `images/catalogue/*.jpg`: enhanced/standardised catalogue reference assets. These are marked **DEMO / SAMPLE** so they are not mistaken for confirmed inventory.

## Commercial-use note
Random Google Images should not be copied into a production catalogue just because they appear in search results. For future demo imagery, use images with an appropriate licence or generated demo imagery. Current web research found free-to-use jewellery references on Pexels, including:

These external references are not downloaded into this ZIP; they are listed for sourcing/approval before production use.

## Catalogue rule
All product cards are enquiry-first. Price, weight, purity and availability are not invented in the frontend. The customer is directed to WhatsApp and the showroom for confirmation.


### Enhanced photo assets
`images/enhanced/` contains the responsive shop hero and enhanced showroom imagery. `images/catalogue/enhanced/` contains cleaned/enhanced 4:5 catalogue assets. These are linked by the live HTML/JS.

Human/owner photos are deliberately excluded from enhancement/retouching.
